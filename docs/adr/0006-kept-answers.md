# 「留到板上」：追问和作业的答案落成页边的一张卡

**状态**：已定（2026-09-22）

这条 ADR 是 **ADR-0005 候选 2 的落地**。那一版里用户当场选的是
「先浮在页边，窗里有一颗「贴到板上」再落卡」，理由是"**板上只有他认可的那些**"，
并且留了一句：「真要落卡，那时才需要给卡片加 anchoring 字段
（`askPage` + 页内归一化矩形），而且必须过一次 `board.js` 的『只在非默认时才写』那一道闸」。

用户 2026-09-22 指的是同一个功能：

> 把答案留住：追问 / 作业的答案关掉就散。

## 背景：为什么现在要动

「框选追问」和「作业辅导」是同一族（`AskBox.jsx` / `HomeworkBox.jsx`）：
浮着、关掉就散、**结构上拿不到 board**。这在"我只是没懂这一点"的时候是对的 ——
一次课下来会问十几处，全落成卡片，板就被问答淹了。

但有两件事它答不了：

- **值得留下的是少数，可你当时不知道是哪几条**。读完一轮问答才判断得出
  "这条讲清楚了"，而那时候唯一的动作是"别关窗"。
- **关掉之后没有任何痕迹**：这一节课你已经花过钱问过、也看懂了，一周后回来
  只剩课件和讲解，那个"我当时卡在哪儿、它怎么讲的"全没了。

所以补的不是"自动留痕"，而是一颗**给用户按的按钮**：你认可哪一条，哪一条才上板。

## 决定

**① 两处各一颗「⬇ 留到板上」，留下的是"你认可的那一段问答"（不是整段对话、也不是光答案）。**

| 从哪来 | 留下的正文 | 为什么 |
| --- | --- | --- |
| 追问（`AskBox`） | 你问的那句话 + 老师的回答；**多轮时留"到这一轮为止"** | 第二轮的答案里常常写着"上面那个符号"——只留答案，一周后看不懂它指的是什么 |
| 作业（`HomeworkBox`） | 题号 + 题干 + 答案 + 解析 | 和「题干要照抄一遍」是同一条理由（防串题、也防"答案：C"孤零零一张卡） |

★ 追问那颗按钮挂在**每一条回答下面**，所以"只想留第一轮"和"想留全部"都是点一下：
按钮的位置就是"留到这儿"的意思。
★ 追问的那句话是**卡片标题**（`cardText` 的 title + 空行 + body），正文才是答案 ——
标题和正文合成一张卡，和讲解卡同一条规矩。

**② 落成一张讲义卡（`rich: true`），贴在那一页的右栏（讲解那一栏）之下。**

- **右栏**：答案就是"老师讲的话"。左栏是提纲（重点 / 公式），不是它的地方；
- **之下**：讲解卡先占了页顶，答案接着往下排。所以两条路必须认同一份"这一页这一栏
  已经占到哪儿了"（`doc-cards.js` 的 `columnOccupancy`）——
  各算一份的话，先贴答案再整理课件，讲解会**正正压在**答案卡上（"压住"在板上看不出来）；
- **同一栏宽**（`SIDE_W = 400`）：它和讲解卡是同一栏里的两块，宽度不一样会像两栏；
- **不单独开第三栏**：多一栏就是板更宽、眼睛要跑更远，而它们本来就是同一栏里的话。

**③ 卡片带 `ask` 字段：「这一问落在课件的哪一块」。**

```json
"ask": { "doc": ".资料/xxx.pdf", "page": 3, "region": [0.12, 0.31, 0.2, 0.06] }
```

- `page` 是必要条件（1 起）；`doc` / `region` 认不出就不写那个键，**不写半个空字段**；
- `region` 是**页内归一化矩形**（`ask-region.js` 已经算好了，存 `[x,y,w,h]` 数组形式）；
- **进关和出关同一个规范形**（`normalizeAsk`），所以"存→读→再存"字节一致；
  老文件、没有问过的卡**一个字节都不多**（和 `locked` / `rich` 同一条闸）；
- 它换来的能力是卡片上那颗 **◎**：点一下，在板上亮出你当时圈的那一块
  （复用追问那圈高亮 `.bd-askmark` 的画法）。没有它，这个字段就是没人读的死字节。

**④ 落卡之后小窗不收，那一轮的按钮变成「✓ 已在板上」。**

留下是"往板上加一样东西"，不是"这一段对话结束了"：
人常常是留下第一条、接着问第二条。所以按钮只把**那一条**标成已留下，窗照旧开着。

**⑤ 答案卡不钉住（不写 `locked`）。**

「课件整理」贴上来的一律钉住（手会蹭、一节课下来版面全乱，见 ADR-0005 末尾）。
答案卡不一样：它是你**亲手**留下的一张，而且多半想立刻挪一下、改两笔；
钉住之后要动它得先找到左下角那颗 📌 —— 对"一次只加一张"来说是白多一步。
想钉住：选中它点 📌（flash 里会这么说）。

## 被否掉的替代方案

1. **只留那一条答案，不留你问的那句话**：卡上写"那这一步为什么成立？"而没有
   指代对象 —— 一周后连"这一步"是哪一步都不知道（和「作业辅导」里
   "题干要照抄一遍"是同一条教训）。
2. **落在视野中心 / 选区旁边**（像粘贴、公式架那样）：那是"搬到眼前的东西"的位置。
   这张卡是**贴着这一页**的素材，重开板、挪一下资料之后就散了。
3. **单独开第三栏**（讲解栏的更右边）：见决定 ②。落到实现上，它能让两条路
   互不打架（不用教 `projectDeck` 认已有卡片）—— 代价是板上多一条空栏。
4. **答案卡一律钉住**：见决定 ⑤。
5. **服务端记会话、由服务端落卡**：服务端没有板，也不该有
   （ADR-0005 决定 ④ 那条"没有状态可错"是这一族的底）。
6. **◎ 改成"鼠标悬停在卡片上就亮"**：用笔的人没有 hover ——
   这一族从头到尾是"手在屏幕上、眼睛在课件上"。

## 后果

- **`check:followup-browser` / `check:homework-browser` 里那条"板上一个字节都不变"
  改了范围**：现在是「**不点「留到板上」就一个字节都不变**」。点下去之后要写进文件，
  而且要能 Ctrl+Z 整步退掉 —— 这两条都得在真浏览器里验，不能只看纯函数。
- `projectDeck` 多一个 **`occupied`** 入参（这一页两栏已经占到哪儿了）。
  **不传 = 一个字节都不变**（老的调用方、老的断言全不受影响）——
  和 `pageGaps` 的"只涨不缩"是同一套账。
- 板文件多一个字段 `ask`（**只在真有的时候写**）。
- 卡片上多一颗 **◎**（未锁定的卡：选中时出现；锁定的卡：和 📌 一起一直亮着
  —— 锁定的卡只剩那几颗按钮能点）。
- **追问的多轮**：留的是"到这一轮为止"。想只留最后一答、或者留整段，
  是同一条路上的两个变体，等真用起来再说（现在不给开关）。
