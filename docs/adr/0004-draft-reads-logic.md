# 草稿里的逻辑是读出来的：板上不猜，草稿里必须有据地猜

**状态**：已定（2026-09-19）

**修订**：2026-09-20 放行了 `say` —— 上面「决定 ③」里"每个字都来自第一趟认回来的行"
这半句被**收窄**了（见文末「修订」一节）。原决定其余部分原样成立。

「▤ 收成笔记」这条链路从此分**两趟**，两趟要的东西正好相反：

| | 干什么 | 怎么切 | 输出 |
| --- | --- | --- | --- |
| **第一趟 · 认字** | 看图，把字认出来 | 按块切，**块要小**（分辨率换准确率） | 每行一段文字（**不再要求它分节、排 Markdown**） |
| **第二趟 · 读逻辑** | 不看图，**纯文本** | **按整板**（"这行属于上一节"切开就没了） | 笔记语法的骨架，**每条都引用行 id** |

四条边界：

1. **板文件一个字节都不改。** 读出来的推导只活在**草稿**里，绝不回写 `board-*.md`
   （ADR-0001 原样成立：连接仍然是宣告的）。
2. **草稿里必须猜。** 因为真板上你几乎不宣告 —— 见下面（一）。
3. **猜必须落行。** 模型说的每一句都要指得出"是哪一行"（本地几何算出来的**行清单** id）；
   指不出来的一律丢掉，而且**报数**，不静默。
4. **"全都靠你宣告"和"全都让模型自由发挥"都不行。** 前者在真板上等于 0 结构，
   后者等于一份你不敢信、只能逐字对图的草稿。

## 为什么

### （一）真板上没有"宣告"，字迹就是全部

拿 `data/` 里 7 张真板量（2026-09-19）：

| 板 | 笔 | 卡 | 板框 | 连接 |
| --- | ---: | ---: | ---: | ---: |
| `board-复变函数.md` | 486 | 2 | 0 | 0 |
| `board-新白板.md` | 439 | 4 | 0 | 0 |
| `board-熵增加.md` | 688 | 1 | 1 | 0 |
| `大物/电磁感应/board-8.1.md` | 5 | 0 | 0 | 0 |
| `大物/电磁感应/board-8.2.md` | 1451 | 1 | 1 | 0 |
| `大物/电磁感应/board-8.3.md` | 546 | 1 | 0 | 0 |
| `大物/电磁感应/board-8.4.md` | 1313 | 0 | 0 | 0 |
| **合计** | **4928** | **9** | **2** | **0** |

`board-8.4.md` 是最干净的那个样本：1313 笔、**0 张卡、0 个板框、0 条连接**——
也就是说今天对它点「收成笔记」，全部内容都只能来自整板转录，结构一个都没有。

用户 2026-09-19 的原话：**「我不会一定直接写出它们之间的关系，所以可能还需要 LLM 推导结合我的笔记」**。

这和 ADR-0001 是**同一形状的证据、相反的结论面**：ADR-0001 用 92:0 证明了
"从形状猜关系"在板上是错的（该杀）；这一条要承认"**等你宣告**"在真板上也是 0
（不能靠）。两头都堵死之后，剩下的位置只有一处：**草稿**。

### （二）今天草稿在笔记界面里**根本不存在**

拿今天真跑出来的那一份（`data/大物/电磁感应/8.2 · 笔记.md`，从 1451 笔的板上收拢的），
用**应用自己的** `parseDoc` 读一遍：

| | 行数 |
| --- | ---: |
| 共 | 67 |
| 行首 `- ` 的条目 | **1** |
| `#` 标题 | 4 |
| 空行 | 28 |
| **散文（`parseDoc` 读不到）** | **32** |

（剩下 2 行是 `> …` 引用段 —— 那是**有意**不成为节点的说明文字，不算。）

→ 树里只有 **5 个节点**。那 32 行读不到的**正是转录的正文**
（`为什么？什么力 洛伦兹力不做功 ∵ …` 那一整段）。

后果是三条一起的：**阅读页签不显示它**（`Preview` 只画 `doc.root.children`）、
**导出不带它**（`export-html.js:48` 用的是同一个 `parseDoc`）、
**`[[引用]]` / 量索引 / 节点树全都看不见它** —— 它只活在原始 textarea 里。
对照：手写的 `示例 · 大物电磁学.md` 52 行里 **0 行**读不到。

这不是"格式不漂亮"，是**收拢出来的东西有一半在第二个界面里是空白**。
根因是一条很具体的规矩：笔记格式**每行一个节点、行首 `- `**（`parse.js` 的 `LEADING`），
而模型回的是**自由 Markdown**。

### （三）逻辑的三个来源，现在只接了一个

| 来源 | 例子 | 现在 |
| --- | --- | --- |
| **可算**（免费、确定） | 行、缩进层级、栏目、谁在谁右边/下面 | ❌ 只用了"竖直大留白"一个信号（`board-note.js:169`） |
| **你说过**（免费、精确） | 板框 = 节、箭头 = 因果/推导/并列/等价、中点旁边的字 = 条件 | ❌ 一个都没读进草稿 |
| **只能猜**（花钱、会错） | 字本身、"这一步为什么接那一步" | ✅ 全压给一次视觉调用 |

第二行要展开说，因为它最冤：

- 板框只按 `f.cards` 成节（`board-note.js:76`）→ **只装手写的框等于不存在**；
- 连接只在末尾摊成一张平表（`board-note.js:111`），而且**只读 `board.links`** ——
  **你画出来的那条线（卡↔卡一笔）根本不进来**；
- `cond`（条件）**一个字都不写**，哪怕 `deriveChains` 早就算得出来、还能标"缺条件"。
- 这些读法**已经在跑了**（`Board.jsx:786` 的 `buildRelations`、`:795` 的 `createLinkReader`），
  只是没有人把它们接到草稿那一头。

### （四）两趟要两种切法

**认字要小图**：一个字在图里占多少像素，直接决定准确率（这是 `splitByBands` 存在的全部理由）。
**读逻辑要大视野**："这行属于上一节"这种判断，切开就没了。

现在是一趟同时干两件事，于是两边都欠着：块切得再细也读不出跨块的关系，
而整板一张图又认不准字。

## 决定

**① 行清单是这一整套的坐标系。**
本地几何先算出一份**行清单**：一撮挨在一起的墨 → 按 y 聚成行 → 按 x 排序 →
每行一个 id、一个包围盒、一个缩进层级（左边缘聚类）。纯函数、不联网、node 里可断言。
**模型引用的一切都只能是行 id。**

- 量级：真板粗算 **7~33 行**（`board-8.4` 1313 笔 ≈ 33 行）—— 对纯文本模型是很小的输入，不值钱。
- ⚠ **行的切法是这一刀里唯一"要量"的地方**：墨挨得近的两行会被聚成一行
  （现成的 `INK_BLOCK_GAP` = 24 是给"连接线中段空白"定的，**不是行距**）。
  阈值要拿真笔迹量出来再定，不能拍脑袋 —— 和 `MIN_DIAG 26` / `LINE_MIN_CHORD 110`
  那一族同一个纪律。
- 失败模式是**退化，不是编造**：行切粗了（整段算一行），结果只是丢缩进层级，
  字还是那些字。这条要保住。

**② 认字与读逻辑分两次调用。**
- 第一次：看图（沿用现有的 `mode:'board'` 通路和分辨率策略），**只干一件事** ——
  把这一块的字按行认出来（行号 + 文字）。分节、排序、Markdown 都不再是它的活。
- 第二次：**纯文本**。输入 = 行清单 + 每行的文字 + 板框 + 你宣告的连接 + 词表；
  输出 = 笔记骨架。
- 为什么值这一次：纯文本调用更便宜、更快，而且**离线可测** ——
  夹具是一份转录 + 一份行清单，断言能钉进 `check-*.js`；
  这一条在"看图那一趟"上做不到，而这一族恰恰是 README 第 23 条说的
  "自动判定的 bug 只出现在更脏的输入上"，没有对手盘就等着翻车。

**③ 只许引用，不许新增。**
第二次调用的输出是**有形状的**：每一行要么是"照抄行 `L17` 的文字"，
要么是一条**断言**（`{kind, 引用行 id…}`）。引用不存在的行 id → 整条丢掉并**报数**
（"N 条读不出来"），不静默降级、不猜一个最近的。
于是"LLM 推导"从一个不可校验的东西，变成**在已知 id 集合上的一个全函数**。
配套的一条：**看不出关系就说看不出**（输出空）—— 和 `BOARD_PROMPT` 里那句
"绝对不要编造内容"同一族。

**④ 输出就是笔记的语法，而且落盘之前拿 `parseDoc` 验一遍。**
`- 标题 | 正文`、两个空格一层、`$…$`、`[[名字]]`；字段**只用 `FIELD_KEYS` 里那几个**，
别的说法一律落成下一层小节点（写错的字段名会静默变成一个子节点 —— README
「字段名：只认这几个」那一节写着）。**读不到的行 = 不存在的东西，当场拦下来。**
理由不是"好看"，是上面（二）那 32 行。

**⑤「结合我的笔记」= 词表 + 语法，两样都本地、可见、可关。**
从 `data/**/*.md` 抽**你自己的词**（`[[名字]]` + 节点标题 + 字段行）当领域提示：
一是发给认字那一趟（专有名词不认错 —— "安培环路定理"被认成别的，是这一族里最烦的一类错），
二是发给读逻辑那一趟（让它用你自己的词说话，`[[引用]]` 才连得起来）。
取词优先级：**同一层**（`data/大物/电磁感应/` 里的板 → 同一层的笔记）→ 关键词命中的其它笔记。

⚠ **这一条会碰到 README 开头那句承诺。** 现在写的是「白板文件永远不上传」，
而词表会让**笔记里的字**出网（只发抽出来的词，不发全文 —— 但仍然是"你的笔记内容出网"）。
规矩照旧，一个字都不放宽：**只有你点了才发生**、**发什么在界面上看得见**、
**关得掉**（和识别本身一样是可选件）。README 开头那段"会联网的只有两个动作"
必须跟着改成三个，并且说清发的是词、不是笔记全文。

**⑥ 校对的是一棵树，不只是字。**
转录校对那一层从"每块一个 textarea"变成"**左边原图 / 右边一棵树**"：
机器读出来的每一层缩进、每一条推导都是**可以点掉的一行**，标着它引用了哪几行；
点一行，左边的图高亮那一块墨。人做的是"**对/不对**"，不是"重排"。

**每一句机器读出来的话都必须看得出是机器说的** —— 和"手写转录（机器认的，还没校对）"
同一个态度。草稿的价值建立在"机器的话可以信一半"上，混进一句看不出出处的，
你就得逐字对图，那比手抄还慢。

## 被否掉的替代方案

1. **全靠你宣告**（板框 + 箭头当骨架，模型只认字）：否掉 —— 7 张真板 0 条连接、2 个板框，
   等于"大部分板收不出结构"。这条路在 ADR-0001 之后本来就是主线，现在是承认它**不够**。
2. **让视觉模型一趟干完**（现状）：否掉 —— 逻辑那半是它最弱的一环，
   而且自由 Markdown 落不进笔记语法（那 32 行）。
3. **让模型自由发挥、不要求引用**：否掉 —— 推不出来的推导没法校验，
   草稿就从"可以信一半"退化成"得逐字对图"。
4. **把读出来的关系写回板文件**（给 `links` 补记录）：否掉 —— 那是把 ADR-0001 整把刀白砍；
   而且板是自动存的，多一个机器写的字段就是多一条假 diff 的来源。
5. **按行切图、一行一个请求**：否掉 —— 一节课几百行就是几百次请求，慢、贵，
   而且**行一多就没有上下文**。行清单是给**纯文本那一趟**用的坐标系，不是拆请求的单位。
6. **本地规则硬推逻辑**（缩进 → 树、箭头 → 因果）：**降级成兜底与交叉验证，不当主路**。
   缩进确实能免费推出一部分层级（那正是行清单要算的），但它推不出"为什么"。
7. **第一趟也按整板发**（省掉分块）：否掉 —— 那正是 `splitByBands` 当初要解决的问题
   （字在图里太小，准确率断崖）。两趟的切法不同，是因为它们要的东西不同。

## 后果

- **板文件不受影响**：这一刀**一个字段都不加**（不加 `structure`、不加 `notes`、不改 `links`）。
  老板在 Git 里纹丝不动。
- **多一次调用**（纯文本，便宜）、**多一份本地计算**（行清单，免费、离线）。
  转录本身仍然**只有你点的时候**才发生。
- **失败模式多了一种**：以前只会"字认错"，现在还会"关系读错"。
  所以②③④三条缺一不可（引用、验语法、标出处），少一条这条路就不该上。
- **草稿的分工要重写**：从"卡片一节 + 转录一节"变成
  "**按板框/留白分节，卡片的字和手写的字在同一个骨架里**"。
  `draftNoteFromBoard`（`src/lib/board-note.js`）是这条路**唯一**的落点。
- **词表是新的出网面**，README 开头那段承诺要跟着改（见决定⑤）。
- **要进 CONTEXT.md 的新词**：**行清单**、**结构整理**（第二趟那次纯文本调用）、**词表**。
  按 `docs/agents/domain.md` 的规矩，词在实现落地时进词表 —— 现在只记在这儿。
- **分期**（活记在 **issue #1**；2026-09-19 定的顺序：**把"不猜"的做完，再上会猜的那一步**）：
  - **第 1 步（不联网、不猜）· 草稿先变成"真笔记"**：转录稿 → 合法笔记行
    （每行 `- `、行内 ` | ` 转全角、`$$…$$` 归一），落盘前拿 `parseDoc` 数一遍
    "读不到的行"（**现状 32，目标 0**）；关系一节补全（`createLinkReader`：
    **你画出来的 + 你宣告的**，带上条件）。**这一步单独就治掉"转录在笔记界面里是空白"。**
    ✅ **做完了（2026-09-19）**：真板实测 **32 → 0**（树里节点 5 → 17）；
    `noteLines` / `unreadableLines` 两个纯函数，断言在 check:board [11]。
  - **第 2 步（不联网、不猜）· 一块 = 一节**：分块改"板框优先、留白兜底"，框名当块名
    —— 你圈的框第一次真的变成笔记的小节，**"只装手写的框等于不存在"到这一步才好**。
    ✅ **做完了（2026-09-19）**：`splitByBlocks`（纯函数）+ 草稿按 `frameId` 把手写落回同名小节
    + 校对弹层显示块名。真板实测：`board-8.2.md` 的「感生电场」（777 笔）→ `## 1、感生电场`，
    `board-熵增加.md` 的「题1」→ `## 1、题1`。
    ⚠ **连带发现并修掉的一件**：切块跟着框走之后，"又宽又扁"的一块会撞上原来的放大规矩
    （倍数只由高度定）—— 真板上量到 **1893×447 → 7797×2011**（1600 万像素）。
    所以加了一道**单边上限** `OCR_MAX_DIM`（`lib/ocr.js` 的 `ocrScaleFor` 一处说了算）；
    长条板/整页板的图**一个像素没变**（check:board [13] 钉着）。
  - **第 3 步（不联网）· 手感**：内容哈希缓存、单块重试、可取消、边认边进校对。
    ✅ **做完了（2026-09-19）**：转录弹层**当场打开**、认完一块填一块；
    认过的块按内容哈希缓存（`lib/ocr-cache.js`，键**不含 id**、空文本不存、
    坏存储静默降级），同样的板再收一次 = **0 次请求**；每块一个「重新认这一块」（绕开缓存）；
    「停止转写」中止后面的请求（**已经发出去的那一次拦不住 —— 界面上如实写着**）。
    断言：check-board [14]（18 条，纯函数 + 假存储）、check-ocr-browser [12]
    （13 条，真浏览器：拿"假服务收到几次请求"当尺子）。
  - **第 4 步（才轮到"猜"）· 读逻辑**：行清单 + 认字按行返回 + 一次纯文本结构整理
    + 落行校验 + 词表。
    ✅ **做完了（2026-09-19）**。实现里改了两处 ADR 原本的说法，都是量出来之后改的：
    · **缩进不给"层级"**：真板上左边缘是**连续铺开**的（113 行：相对中位 p75 = 44px、
      p90 = 195px、max = 413px）。第一版按最左那行当基线量化成 0/1/2 层，
      **55.8% 的行被判成"缩进两层"** —— 只因为最左那一行是个孤例。所以本地层只给
      `x0Rel`（一个事实），判断留给第二趟（它有文字可看）。
    · **行间空隙也不给**：块边界本来就是按大留白切的（`splitByBands` minGap 90），
      一块之内已经不存在"大空隙"了（实测块内 max 89px），没有信息量。
    量到的规模：真板每块 **2~20 行**、一张板 11~36 行；一张 22 行的板，
    第二趟的输入整段 **751 字**（纯文本，比一张图便宜得多）。
    实现分布：`ink-lines.js`（行清单）、`board-structure.js`（契约 + 落行校验 + 渲染）、
    `note-vocab.js`（你自己的词）、`server-ocr.js` 的 `BOARD_LINES_PROMPT` / `STRUCT_PROMPT`
    + `/api/structure`（**不看图的第二个口**）。
    断言：check-board [15]/[16]/[17]/[18]、check-ocr-server（提示词与两个口的形状）、
    check-ocr-browser [13]（真浏览器整条跑通：按行回话 → 报覆盖率 → 纯文本第二趟 →
    框名成小节 + 缩进 + 关系，而且"读不到的行 = 0"）。
  - 为什么这么排：**行清单本身产不出看得见的东西** —— 它要等"认字按行返回"才有坐标可用；
    而"块 = 节"正是第 4 步要用的坐标，第 3 步的缓存让第 4 步的调试快一个数量级。
    每一步都留下一个可断言的东西，**唯一会猜的那一步排在最后**。
  - `deriveChains`（推导链）**跟着第 4 步走**：链是要"织进嵌套"的，
    而现在草稿里连嵌套都还没有 —— 第 1 步先把每条连接摊平写清楚（带条件）就够。
- **对手盘**：这一族是"自动判定"那类代码（README 第 23 条的教训）——
  动它必须拿真板量"凭空多出几条 / 少了几条"，**不能只跑自己造的夹具**。
  `.cache/board-baseline.md` 和 `data/大物/电磁感应/board-8.4.md`（1313 笔、零卡片）
  是现成的两个对手盘。

## 修订（2026-09-20）：`say` —— 放行一小段机器自己写的话

**改的是哪一条**：上面「决定 ③ 只许引用，不许新增」的后半句
（"每个字都来自第一趟认回来的行"，以及提示词里那句"文字一个字都不许它写"）。

### 为什么改：原决定在真板上等于"只有骨架"

用户拿到第一份真跑出来的草稿（`data/大物/电磁感应/8.2 · 笔记.md`）之后的判据是：

> **「纯粹只是并列式的把我的笔记碎片化列了出来，完全没有任何的逻辑，完全没有体现出来
> LLM 对与我的笔记的理解与整合，象是纯粹的识别啊」**

这句判据落在原决定的最痛处：第 4 步读出来的东西（**这几行到底在讲什么**）**一个字都没地方放**。
模型只能重排行号 —— 于是它能干的全部事情就是"把你写的行摆成一棵树"。
一份只有骨架、没有一句人话的草稿，读起来和"识别结果 + 缩进"没有区别。

（顺带查出的一个**真 bug**，也是这份草稿看上去像"纯粹识别"的直接原因：
`recognizeHandwriting` 从来没把行清单 append 进请求体 —— 调用方在传、服务端在读，
中间那一跳断了，于是服务端每次都退回老的 `BOARD_PROMPT`、模型自由分行、
`parseLineOutput` 判 `followed=false`、`items` 是 null、**整条第 4 步在真跑的时候是死的**。
修在 `src/lib/ocr.js`；对手盘见 check-ocr-browser [13] 那条"认字那一趟的提示词里必须带行清单"。
这条与本节的决定无关，但它说明"只有骨架"这件事当时连骨架都没发生。）

### 改成了什么：一节一段，标出来

`STRUCT_PROMPT` 的输出多一个字段：

```json
{ "sections": [ { "title": 3, "frame": null, "say": "这一节在讲什么，一到三句", "rows": [ … ] } ] }
```

`say` 是**整条链路里唯一放行机器写字的地方**，落进草稿时排在这一节最前面，
前缀 `〔机器整理〕`（**由我们加**，不靠模型自觉）：

```markdown
## 1、感生电场
- 〔机器整理〕变化磁场在空间里激出涡旋电场，它的环流就是感应电动势。
- <你板上的第 1 行>
  - <你自己缩进的那一行>
```

### 四条护栏（放行 ≠ 放开）

1. **只有这一处**：`sections[].say` 是唯一的自由文本；行的文字、小节名、关系两头，
   照旧**只许引用行号**（原决定 ③ 的前半句一个字没动）。
2. **只许用这一节已有的东西**：不许引入新量、新数字、新结论 —— 提示词里明写三个不许。
3. **必须标出来**：标记由我们加，而且草稿开头多一句说明"哪一种是机器写的、哪一种是你写的"
   —— 和"手写转录（机器认的，还没校对）"同一个态度。
4. **看不出来就别写**：`say` 缺席/空 → 这一节跟从前**一字不差**（不硬凑）。
   另外它**只占一行**（多行压成一段、行内 ` | ` 转全角），超 240 字截断并**记一笔**。

### 什么没变

- **板文件照样一个字节都不动**（ADR-0001 原样成立）。
- **转录那一趟照样一个字不改**（`L<行号>|` 是契约）。
- **每一行都还追得到出处**：`say` 是唯一"来源是模型"的内容，而它**自己带着标记**。
- 失败模式多了一种（"整理的那段话说错了"），代价是**看得见**的 —— 它在最显眼的位置、
  带着标记、且原文就在它下面一行。这正是它敢放行的理由。

### 断言

`check:board` [16]（`say` 收下 / 标记是加上的 / 它是一条合法笔记行 / 脏输入压平 /
缺席与空 → 不写 / 太长截断并报数）、`check:ocr-server`（提示词里"除了 `say`"这句在，
三个不许在，"看不出来就写 null"在）、`check-ocr-browser` [13]（真浏览器里落进草稿、
带着标记、而且"读不到的行 = 0"没被它弄回去）。
